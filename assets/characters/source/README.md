# ASENQ character movement concepts

Six affiliations, six human variants each, eight pose columns per variant.

Columns left to right: idle A, idle B, walk A, walk B, work A, work B, send A, send B. Rows are separate human variants, not model names.

All six PNGs contain genuine transparency. These are unofficial costume concepts. They need per-frame cropping, baseline alignment, identity/accessory cleanup and timing before animation use. Some walk pairs have limited motion differences. These raster sheets are visual references for strict character-cell TUI sprites. No runtime animation has been implemented.
